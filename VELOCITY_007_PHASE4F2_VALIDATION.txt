Environment limitations:
- Cargo/Rustc are not installed, so the Tauri application and the new shared Rust BTC wallet service were statically inspected but not compiled here.
- The system OpenSSL is 3.0.13 and does not provide ML-DSA-65. Wallet/signature integration tests that require QRX's OpenSSL >= 3.5 PQC build could not run in this environment.
- No private Kraken credentials were provided and no real Kraken order was submitted.

The live feature must remain opt-in and should first be exercised with small limits.
