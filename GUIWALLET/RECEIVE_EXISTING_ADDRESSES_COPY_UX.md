# Receive existing-address UX

- Receive now loads `listaddresses` when the wallet opens and when the Receive view is selected.
- The first stored address is shown immediately and rendered as a local QR code.
- All stored wallet addresses are shown with Show QR and Copy controls.
- Generating a new receive address is explicitly optional and does not replace/remove existing addresses.
- Available Core wallets show a copy-address control for every wallet whose address is known.
